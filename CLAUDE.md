# Instructions pour ce dossier

## Langue

Toujours travailler en français.

## Règles non-négociables

- Ne JAMAIS utiliser les termes « éducation positive », « renforcement positif » ou « méthode coercitive » pour décrire les services ou l'approche de Kind Dog Training.
- Ne jamais catégoriser l'approche dans un courant étiqueté.
- Toujours vouvoyer le lecteur.

## Écriture — réflexes de base

S'applique à tout ce que tu écris (articles, emails, notes, réponses). Pour un scrub complet d'un brouillon, invoquer le skill `avoid-ai-writing`.

- Mène par le point, pas par le contexte. Une idée par phrase, voix active, verbes forts, contractions ok, première personne ok quand pertinent.
- Bannis : plonger, tirer parti, robuste, fluide, holistique, exhaustif, pivotal, méticuleux, transformateur, embrasser, en constante évolution, tapisserie, paysage / royaume (métaphores), afin de, au bout du compte, il convient de noter que, quand il s'agit de, dans le monde d'aujourd'hui.
- Pas de tirets cadratins (—) comme rythme. Virgule, point ou parenthèses.
- Pas de "ce n'est pas X, c'est Y", pas de "le meilleur : Y", pas de "voyons" / "décomposons", pas de "en conclusion", pas de "tu n'es pas seul".
- Pas de règle de trois par défaut, pas de hedges empilés (pourrait potentiellement…), pas de gras mid-phrase, pas d'emoji dans les titres.
- Sois concret : chiffres, noms, exemples. Fait non vérifié → demande, jamais inventer.
