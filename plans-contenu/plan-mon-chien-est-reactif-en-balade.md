## Lacunes identifiées

- Le concept de "cumul de stress" (trigger stacking) — plusieurs stimulations successives qui font déborder le chien — n'est pas couvert explicitement dans la base de connaissances, bien que le mécanisme soit décrit implicitement à travers la frustration et la surcharge émotionnelle. Pourra être évoqué via les cas terrain (Tanos, Vaillant) sans développement théorique isolé.
- Le ressenti du propriétaire (honte en balade, isolement social, découragement) est un angle différenciant identifié dans la recherche SEO mais peu documenté dans la base de connaissances. Pourra être mentionné dans le H2-2 ou l'introduction via le vécu de Mélyne avec Ramsey, sans en faire une section autonome.
